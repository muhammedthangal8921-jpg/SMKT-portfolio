1. OPEN IT ON YOUR COMPUTER
Download the ZIP. Right-click it in Windows and select Extract All.
Open the extracted SMKT-Portfolio folder, then double-click index.html.
Keep index.html, style.css, script.js and assets together in the same folder.

2. EDIT IT IN VS CODE
Open VS Code. Choose File > Open Folder and select SMKT-Portfolio.
Edit index.html for your name, services, qualifications and projects.
Use Ctrl+F to find the text you want to change. Keep HTML tags intact.
Edit style.css for colours and layout. Later rules override earlier rules;
the section beginning 'Midnight surfaces' controls the upgraded theme.
Edit script.js only when you want to change scroll-reveal behavior.
Press Ctrl+S to save, then refresh the browser to see your changes.
If styles appear unchanged after an update, try Ctrl+F5 in the browser.

3. PUBLISH UNDER YOUR GITHUB ACCOUNT
Sign into your own GitHub account and create a public repository, such as
smkt-portfolio. Upload index.html, style.css, script.js and assets to its top level.
Upload the extracted files, not the ZIP or an enclosing folder.
Save/commit the files to the main branch.
Open repository Settings > Pages. Under Build and deployment, choose
Deploy from a branch. Select main and /(root), then Save.
When deployment finishes, GitHub Pages settings shows your website link.
A project URL usually follows https://YOUR-USERNAME.github.io/smkt-portfolio/.
Use the actual URL GitHub displays. Future changes to the publishing branch
are published automatically. GitHub Pages supports public repositories on
GitHub Free. Your uploaded repository source is also public.

4. HOW CONTACT WORKS
Contact buttons open the visitor's email application with your address and,
where applicable, a subject. They do not send messages automatically or
store enquiries. The visitor needs an email application configured, or can
copy your displayed email address into their email service.

sync with the portfolio hosted in ChatGPT. Publishing on another host does
not change your existing ChatGPT site's access settings.
There is no admin dashboard in this copy; manage content through the files.
